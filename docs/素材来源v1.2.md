# 四章素材来源与适配 v1.2

素材来自项目维护者提供的 peter-rabbit-interactive-kit.zip 与 Comic Companion PDF。四章 C 字典、S 说话人和 V 声线表仅通过 AST 静态读取，未导入或运行原生成脚本。每章气泡文本与 peter_data.json 逐项比对；作业答案从 C.answers 的首段抽取，再按各格空格数量分配。第三章图片文件的完整 PNG 名称自动映射到 ZIP 中对应 JPG。

第一至四章分别有 7、8、8、9 个漫画气泡，均为 6 格、10 句课文、5 张词卡。图片共 49 张，每张提供 WebP 与 JPG；音频分别 51、52、50、51 条，共 204 条。模型和声音库位于 Git 之外。统一 MP3 24 kHz、64 kbps、单声道，保留句中停顿，仅裁除首尾静音并归一化。

## 文字与图片适配

- 第二章 shoe/sparrow 在作业中自动变为 shoes/sparrows，保持宝箱单数与复数提示。第三章句首 Mouse 自动大写；第四章 run 可重复使用两次，分别显示 Run/run。验证不把大小写差异当作拼写错误。
- 第三章 can 的词卡和弹卡补充“喷壶（watering can）”，源中文保留在 sourceZh，英文与例句不变。池塘图中的喷壶为灰色，绿色问答旁补上素材包中绿色喷壶词卡，不改原句。
- 漫画气泡按 PDF 265.1378×197.9696 pt 基准换算，原矩形留在 sourceRect。新增章节为小屏阅读微调气泡位置和宽度。尾巴保持或按示范角色修正；真实截图单独核对。
- 第三章大场景两处空白框加 HTML 装饰标签 LOOK!/FIND 6，未遮住任何找物目标；SEED SACK 背景文字保留。第四章大场景只用 CSS 裁去原模糊边缘，原图片文件完整保留；裁切框及换算后的热区保存在 JSON。
- 三章各六种找物目标均可见，未删除目标。第二章 8 个区域，第三章 17 个，第四章 8 个，同类物品多处可点击；第一章仍为 13 个区域。百分比坐标以实际显示图左上角为原点，点击增加触摸容差。
- Act it out 依据 lesson 演练：第二、三章 Peter/McGregor，第四章 Peter/Mum/McGregor。麻雀句自动读出。无录音、无麦克风、无发音评分。
