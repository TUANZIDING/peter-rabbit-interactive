## 使用与隐私

在iPad/iPhone Safari或Mac浏览器打开在线书架，第一次点“开始”解锁音频。线上使用不需要Mac本地服务器。

进度保存在各设备、各浏览器及当前网址的localStorage，不能跨设备同步。本地localhost网址与线上GitHub Pages网址的进度分别保存；发布操作没有迁移或清除用户原本的本地印章。

模型、原素材压缩包、完整本地QA目录、机器日志、个人路径和局域网地址没有上传。代码、网页图片和音频为公开内容。原著、AI插图及字体来源见[素材来源](素材来源v1.2.md)。

真实iPad/iPhone试用仍由家长确认，自动化WebKit不等同于真实设备验证；没有录音、发音评分或学习成效验证。
