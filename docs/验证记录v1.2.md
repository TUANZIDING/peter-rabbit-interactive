## 复现

```sh
python3 -m http.server 8817
python3 tools/checkv1.1.py
for chapter in 1 2 3 4; do
  PETER_QA_CHAPTER="$chapter" node tools/browser-checkv1.1.mjs
done
node tools/visual-checkv1.0.mjs
node tools/hotspot-checkv1.0.mjs
```

需 Python/Pillow、FFmpeg/ffprobe、Node/Playwright 与 Chromium/WebKit。浏览器测试默认端口8817；可设 PETER_PLAYWRIGHT_MODULE、PETER_QA_URL 和 PETER_QA_OUTPUT。默认截图写入 reports/，该完整本地目录不随发布。

## 已知边界
